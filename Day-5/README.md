# Day 5: Convert a List of Tuples into a Dictionary

In this problem, I converted a list of tuples into a dictionary using a `for` loop instead of the built-in `dict()` function.

I created an empty dictionary and used tuple unpacking to get each key and value. Then I added them to the dictionary inside the loop.

## Concepts used
- For loop
- Tuple unpacking
- Dictionary creation and assignment

## What I learned
How to create a dictionary manually from a list of tuples using a loop.
